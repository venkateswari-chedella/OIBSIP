Digital Library Management System

This project is a console-based Digital Library Management System developed using Java.

Features

- Add new books
- Display all books
- Search books by title
- Issue books
- Return books
- Check book availability
- Menu-driven interface

Technologies Used

- Java
- ArrayList
- Scanner
- Classes and Objects
- Conditional Statements
- Loops

How to Run

Save the Java file as:

"DigitalLibrary.java"

Compile:

javac DigitalLibrary.java

Run:

java DigitalLibrary
