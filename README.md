📌 Tasks

Task 1 — Online Reservation System

A console-based railway reservation system.

Features

- User login
- Reservation
- Cancellation
- Passenger details
- PNR generation
- Ticket details

Folder: "Task1-OnlineReservationSystem"

---

Task 2 — Number Guessing Game

A simple Java game where the computer generates a random number and the user tries to guess it.

Features

- Random number generation
- User input
- Guess checking
- Number of attempts
- Winning message

Folder: "Task2-NumberGuessingGame"

---

Task 3 — ATM Interface

A console-based ATM simulation.

Features

- PIN authentication
- Check balance
- Deposit money
- Withdraw money
- Exit option

Folder: "Task3-ATMInterface"

---

Task 4 — Online Examination

A console-based online examination system.

Features

- Student login
- Multiple-choice questions
- Answer submission
- Automatic score calculation
- Percentage calculation
- Pass/Fail result

Folder: "Task4-OnlineExamination"

---

Task 5 — Digital Library

A console-based library management system.

Features

- Add books
- Display books
- Search books
- Issue books
- Return books
- Check book availability

Folder: "Task5-DigitalLibrary"

---

▶️ How to Run

Open the required task folder and compile the Java file.

Example:

javac DigitalLibrary.java

Then run:

java DigitalLibrary

The same process can be followed for the other tasks.
