Number Guessing Game

Oasis Infobyte – Java Development Internship

Project Overview

The Number Guessing Game is a simple Java console application where the computer generates a random number between 1 and 100. The player must guess the number within a maximum of 7 attempts.

Technologies Used

- Java
- Java Random
- Java Scanner
- Object-Oriented Programming

Features

- Random number generation from 1 to 100
- User input for guesses
- Too High and Too Low hints
- Attempt counter
- Maximum 7 attempts per round
- Correct answer detection
- Score calculation
- Play Again option
- Total score tracking
- Game summary

How the Game Works

1. The computer generates a random number between 1 and 100.
2. The player enters a guess.
3. The game displays Too High or Too Low if the guess is incorrect.
4. The player has a maximum of 7 attempts.
5. If the correct number is guessed, the round score is calculated.
6. If all attempts are used, the correct number is displayed.
7. The player can choose to play another round.
8. The final total score is displayed.
