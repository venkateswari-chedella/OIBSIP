Online Reservation System

Oasis Infobyte – Java Development Internship

Project Overview

The Online Reservation System is a Java-based desktop application designed to simplify train ticket reservation and cancellation. It provides a user-friendly interface for login, reservation, and ticket cancellation.

Technologies Used

- Java
- Java Swing
- JDBC
- SQLite Database
- Object-Oriented Programming

Features

- User Login
- Train Reservation
- Automatic train name retrieval using train number
- Passenger details entry
- Unique PNR generation
- Reservation confirmation
- Ticket cancellation using PNR
- Reservation validation
- Database storage

How It Works

1. The user opens the application.
2. The login screen verifies the user.
3. The reservation screen allows the user to enter passenger and train details.
4. A unique PNR is generated after successful booking.
5. Reservation details are stored in the database.
6. The user can cancel a reservation by entering the PNR.
7. The system displays confirmation messages for successful operations.
