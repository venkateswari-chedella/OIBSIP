ATM Interface

Task 3

A simple ATM Interface developed using Java. This project allows users to securely access an ATM menu using a PIN and perform basic banking operations.

Features

- PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Insufficient balance validation
- Exit option
- Menu-driven interface

Technologies Used

- Java
- Scanner Class
- Switch Case
- Loops
- Conditional Statements

Default PIN

1234

Initial Balance

₹10,000.00

Sample Output

===== ATM INTERFACE =====
Enter PIN: 1234

===== ATM MENU =====
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

Enter your choice: 1
Current Balance: ₹10000.00

How to Run

1. Download or clone this repository.
2. Open "Main.java".
3. Compile the program:

javac Main.java

4. Run the program:

java Main
